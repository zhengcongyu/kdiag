# KDiag v0.1.0 — Explainable Kubernetes Diagnostics MVP

This file is the planned release note body. It must not be used to publish a
release until every item in the release checklist is verified.

## Implemented

- client-go informer collector abstraction for nine Kubernetes resource kinds.
- UID-based in-memory topology and local graph queries.
- Event normalization, fingerprinting, deduplication, and incident aggregation.
- Thirteen deterministic rules with supporting, contradicting, and missing evidence.
- Asynchronous REST/SSE diagnosis API, PostgreSQL repository, Web console, and CLI.
- Static Kubernetes network-path analysis and guarded probe interfaces.
- Docker, Helm, and seven kind fault scenarios.

## Demo

`make kind-up && ./deploy/kind/run-e2e.sh targetport`

## Known limitations

- No built-in authentication or multi-tenant authorization.
- Live collector-to-repository wiring and production NetworkPolicy semantics
  require further integration.
- CNI traffic visibility and active probes are not part of the default runtime.

## Security

Read-only RBAC, no Secret content collection, non-root containers, parameterized
SQL, target-allowlisted typed probes, minimal workflow permissions, and secret/
dependency/container scanning are configured.
