# KDiag v0.5.0 — Explicit resource health and complete English UI

## What changed

- Removed the ambiguous `observed` / `已采集` state. Every visible resource is
  now classified as healthy, warning, critical, or unknown.
- Added structured evaluations for configuration-oriented resources including
  ConfigMap, CronJob, Ingress, NetworkPolicy, and StorageClass.
- Unknown means KDiag cannot safely establish health from the available
  structured evidence. It never means healthy.
- Completed English localization for inventory, diagnosis, network path,
  incident, topology, replay, reports, policies, and settings workflows.
- Added English explanations for resource health summaries and an automated
  regression test that rejects Chinese text in the main English workspace.

## Safety

- Kubernetes access remains read-only.
- Secrets are not collected or displayed.
- NetworkPolicy configuration validity does not claim real traffic
  connectivity; CNI telemetry or an active probe is still required.
- Active probes remain disabled by default.

## Upgrade

```bash
helm upgrade --install kdiag deploy/helm/kdiag \
  --namespace kdiag --create-namespace
```

The default image tags and Chart application version are `v0.5.0`.
