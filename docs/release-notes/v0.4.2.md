# KDiag v0.4.2 — Web Rollout Cache Safety

v0.4.2 fixes a blank page that could appear when a browser reused the HTML
shell from an older deployment after the corresponding content-hashed
JavaScript file had been replaced.

## Fixed

- `index.html` and client-side routes now use `no-store, no-cache`.
- Content-hashed `/assets/` files use immutable long-lived caching.
- Missing asset URLs return `404` instead of returning HTML to a JavaScript
  module request.

All permission visibility, explicit resource status, and Chinese/English
console features from v0.4.1 remain unchanged.
