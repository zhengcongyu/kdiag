# KDiag

KDiag is an explainable Kubernetes incident diagnosis, network troubleshooting,
and change-verification platform. It is under active development toward the
v0.1.0 MVP described in [the roadmap](docs/ROADMAP.md).

The repository currently contains the architecture and executable project
skeleton. Only verified capabilities are promoted to this README as milestones
are completed.
